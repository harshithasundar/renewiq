# RenewIQ

## Vision
RenewIQ is a subscription management platform that helps users track recurring payments, receive renewal reminders, analyze subscription spending, and gain AI-powered financial insights.

## MVP Features

- User Authentication
- Dashboard
- Add/Edit/Delete Subscription
- Categories
- Search & Filter
- Analytics
- Calendar
- Renewal Notifications

## Future Features

- Gmail Integration
- OCR Receipt Scanner
- AI Recommendations
- Family Sharing
- Price History
- Budget Planning
